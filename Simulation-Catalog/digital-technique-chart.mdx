The Digital Technique simulation is based on a digital radiography (DR) technique chart. The chart pairs each anatomical part and projection with reference values for kVp, mAs, source-to-image distance (SID), and image receptor (IR) size.

The tables below reproduce the reference values from **TECHNIQUE CHART – completed for DR** for anatomy covered by the current simulator modules, grouped to match the Simulation Catalog. Use them to understand the simulation's technique reference and plan exposure comparisons in your teaching.

## How to read the chart

| Field | Meaning |
| --- | --- |
| Part and projection | The anatomical area and view listed in the source chart. |
| kVp | Peak kilovoltage: the tube voltage used for the exposure. |
| mAs | Milliampere-seconds: the product of tube current and exposure time. |
| SID | Source-to-image distance, measured from the X-ray source to the image receptor. All table values are in inches. |
| IR size | Image receptor dimensions from the source chart, in inches. These describe the source setup, rather than the detector sizes available in every simulator module. |

The source chart lists a **speed value of 400 for every entry**. This common value applies to all rows below. It is source-chart context, not an exposure index (EI), target EI, or deviation index (DI).

For comparison with a distance display in centimetres: **40 in = 101.6 cm**, **60 in = 152.4 cm**, and **72 in = 182.88 cm**.

Projection abbreviations include **AP** (anteroposterior) and **PA** (posteroanterior). **X-table** means cross-table.

## Using the reference in the simulator

The technique chart and the simulator catalog answer different questions. The chart records the reference exposure settings; the [Simulation Catalog](/Simulation-Catalog/browse-by-region) describes the available anatomy, confirmed projections, detector setups, and limitations. A row in this chart does not by itself confirm that the corresponding exam or projection is supported.

For a supported setup, find the relevant part and projection and use its kVp, mAs, and SID as a reference for your comparison. Keep the case, positioning, collimation, and image processing settings consistent while changing one technical factor at a time.

The simulator offers raw and processed digital image modes. Processing can change brightness and contrast, so image brightness alone does not show whether exposure is appropriate. Where available, include the displayed EI, target EI, and DI in the discussion. See [image and exposure capabilities](/Simulation-Catalog/capabilities#control-room-and-image-review) and the teaching activity [Explore kVp, mAs, and distance](/Guides/Teaching-with-Desktop/activities-and-templates#explore-kvp-mas-and-distance).
